# עיצוב מחדש של WordQuest — כיוון "מדבקה"

תאריך: 2026-08-20
סטטוס: מאושר לתכנון מימוש

## הבעיה

האפליקציה נראית חובבנית. האבחון העלה חמישה גורמים קונקרטיים, שכולם החלטות סבירות בנפרד שהצטברו בלי סולם מרכזי:

1. **אמוג'י כאייקונים.** `getCategoryEmoji` ב-`CategoryGrid.tsx` ממפה שמות קטגוריה לאמוג'י לפי התאמת מחרוזת. אמוג'י נראה שונה בכל מערכת הפעלה, לא מקבל את צבע המותג ולא מתיישר לרשת.
2. **היררכיה שטוחה.** `font-black` (900) על כל כותרת, `uppercase` עם `tracking-widest` על כל טקסט משני. כשהכול מודגש, שום דבר לא בולט.
3. **צבע חסר משמעות.** מערך `THEMES` מקצה גרדיאנט לפי `id % 6`, ולצידו `gradient-primary`, `gradient-mint` ו-`gradient-sun`. הצבע אקראי ולא מקודד מידע.
4. **סולמות לא עקביים.** שישה רדיוסים (`xl`–`5xl`, `full`) ושישה צללים, כולל `shadow-pop` בטווח 70px על כרטיסים קטנים.
5. **שלוש שפות עיצוב.** מסכי תלמידות בהירים-ורודים, מסכי אדמין כהים, מסכי הקלטה בכחול נייבי.

## המטרה

מלוטש **וגם** משחקי. ההבחנה המנחה: עיצוב חובבני שואב משחקיות מ**ברירות מחדל** (אמוג'י של מערכת ההפעלה, גרדיאנט אקראי); עיצוב מלוטש שואב אותה מ**מלאכה** (אייקון שצויר בכוונה, צבע שנבחר כי הוא אומר משהו, עומק שנבנה במכוון).

לילדים צריך צבע **יותר** נועז, לא פחות — אבל נושא משמעות.

### לא במטרה

- שינוי בלוגיקה, בסכימה או בזרימת הנתונים.
- שינוי במנוע האפקטים (`effectsRegistry.ts`, `useEffectEngine.ts`). הקונפטי והאנימציות נשארים; משתנה רק המשטח שעליו הם רצים.
- שינוי ב-TTS, בהתחברות או בשיוך הקטגוריות.

## שפת העיצוב

שפה של מדבקה / משחק קופסה: קו מתאר כהה, צל מוצק, צבע שטוח נועז, גופן עגול.

### צבע — חמישה עם תפקיד

| טוקן | ערך | תפקיד |
|---|---|---|
| `ink` | `#2A1B10` | קווי מתאר, טקסט, צללים |
| `cream` | `#FFF8EE` | רקע האפליקציה |
| `surface` | `#FFFFFF` | כרטיסים, שדות |
| `muted` | `#7A6555` | טקסט משני |
| `line` | `#E8DCCB` | מפרידים דקים |
| `sun` | `#FFD166` | מותג, הדגשה |
| `mint` | `#06D6A0` | הצלחה, התקדמות |
| `berry` | `#EF476F` | שגיאה |
| `sky` | `#4CC9F0` | פעולה, ניווט |
| `track` | `#F2E8DA` | רקע פס התקדמות, מצב לא-פעיל |

טקסט על כל צבעי המותג הוא `ink` — לא לבן. יחסי הניגודיות של `#2A1B10` על `sun`/`mint`/`sky` עוברים AA בנוחות.

**נמחקים מ-`tailwind.config.js`:** מערך `THEMES`, `gradient-primary`, `gradient-mint`, `gradient-sun`, `mesh-warm`, `mesh-cool`, והכינויים הישנים (`purple`, `pink`, `text`).

### טיפוגרפיה — Rubik

מחליף את Heebo. תמיכה מלאה בעברית, מרגיש ידידותי בלי להיות ילדותי.

| שימוש | גודל | משקל | נוסף |
|---|---|---|---|
| כותרת מסך | 26px | 700 | `letter-spacing: -0.02em` |
| כותרת כרטיס | 17px | 700 | |
| מילה במשחק | 32px | 800 | `letter-spacing: -0.02em` |
| גוף | 14px | 500 | |
| תווית | 12px | 600 | `color: muted` |

`font-black` (900) ו-`uppercase`+`tracking-widest` מוסרים מכל האפליקציה.

### רדיוס — שלוש מדרגות

`sm: 10px` (שדות), `md: 20px` (כרטיסים), `pill: 999px` (תגיות). כל השאר נמחק.

### עומק — צל מוצק

| שם | ערך |
|---|---|
| `solid-sm` | `2px 3px 0 #2A1B10` |
| `solid` | `3px 4px 0 #2A1B10` |
| `solid-lg` | `5px 6px 0 #2A1B10` |
| `solid-pressed` | `1px 1px 0 #2A1B10` + `translate(2px, 3px)` |

קו מתאר: `2.5px solid ink` על אלמנטים אינטראקטיביים ומורמים; `2px` בטבלאות האדמין הצפופות.

מצב לחיצה מזיז את האלמנט פיזית — משוב מיידי בלי אנימציה. כל הצללים המטושטשים (`soft`, `lift`, `pop`, `glow-mint`, `glow-rose`, `inner-soft`) נמחקים.

### אייקונים

קובץ חדש `src/shared/ui/icons.tsx` עם כ-20 אייקוני SVG כרכיבי React: `stroke-width` 2.4, `stroke-linecap="round"`, `currentColor`, ללא מילוי. יושבים על אריח צבעוני עם קו מתאר וצל מוצק.

`getCategoryEmoji` ב-`CategoryGrid.tsx` מוחלף במיפוי שם-קטגוריה → רכיב אייקון, עם אייקון ברירת מחדל לשם לא מוכר.

האמוג'י בהקשרים שאינם אייקונים (🎁 להטבות, 🔥 לרצף, 🏆 להישגים) **נשאר** — שם הוא תוכן, לא ממשק.

## החלה על המסכים

### רכיבים משותפים (`src/shared/ui/`)

`Card` — הווריאנטים `glass`/`gradient` נמחקים ומוחלפים ב-`solid` יחיד עם קו מתאר וצל מוצק. `interactive` מקבל את מצב הלחיצה.
`Button` — `sky` לפעולה ראשית, `mint` לאישור, `berry` להרס, `track` למשני.
`Badge` — תגית pill עם קו מתאר.
`Input` — קו מתאר 2.5px, רדיוס 10px.
`Modal`, `Table`, `Toggle`, `GlobalProgress`, `LoadingOverlay` — מיושרים לאותם טוקנים.

### מסכי תלמידות

`Login`, `Register`, `AvatarPicker`, `CategoryGrid`, `GameScreen`, `RewardChooser`, `UserProfile`. ה-blur blobs המונפשים (`animate-breathe` על שלושה עיגולים מטושטשים) ב-`Login` ו-`CategoryGrid` נמחקים.

**כרטיס קטגוריה:** אריח אייקון + תגית התקדמות למעלה, כותרת, שורת "עוד N מילים לסיום", פס התקדמות עם קו מתאר. `completed` מסומן בתגית `mint`, לא ב-`ring`.

**מסך המשחק:** שורת נקודות התקדמות למעלה (ירוק=נכון, חרדל=נוכחי, `track`=טרם), כרטיס שאלה מרכזי, כפתור השמעה עגול, שדה קלט, CTA ירוק.

### מסכי משחק מיוחדים

`MichelGameScreen` ו-`RecordingGameScreen` מאבדים את הגרדיאנט `#050A1C → #0b1c3a` ועוברים לשפה הבהירה. **הערה:** אין להם כרגע משתמשות פעילות, ולכן הסיכון נמוך.

### מסכי אדמין

עשרת המסכים תחת `features/admin/` עוברים מכהה לבהיר — אותם טוקנים, גרסה צפופה: קו מתאר 2px, `solid-sm`, ריווח קטן יותר, בלי אריחי אייקון גדולים. זה מה שמבטל את "שלוש אפליקציות באחת".

## סדר המימוש

1. טוקנים — `tailwind.config.js` ו-`styles.css` (כולל החלפת הגופן).
2. `icons.tsx`.
3. רכיבי `shared/ui/`.
4. מסכי תלמידות.
5. מסכי משחק מיוחדים.
6. מסכי אדמין.
7. ניקוי טוקנים מתים מ-`tailwind.config.js`.

שלבים 1–3 חייבים לקדום את 4–6, כי כל השאר צורך אותם. 4, 5 ו-6 בלתי תלויים זה בזה.

## אימות

אין ריצת בדיקות בפרויקט — `tsc` (דרך `npm run build`) הוא שער הנכונות היחיד.

- `npm run build` עובר אחרי כל שלב.
- בדיקה ידנית בדפדפן של כל מסך, בעברית RTL, ברוחב מובייל וברוחב שולחני.
- בדיקה חזותית שאין שאריות: `grep` על `font-black`, `tracking-widest`, `surface-glass`, `bg-mesh`, `gradient-primary`, `shadow-pop`, `getCategoryEmoji`.
- מסכי האדמין נבדקים כשהם מחוברים, כי הם לא מוגנים ב-route guard.
